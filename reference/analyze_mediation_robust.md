# Run all mediation estimators on one synthetic dataset

Reference-named entry point: applies UNADJ, DIRECT, COCA, IV2SLS, and
PGC (matrix bridge) mediation estimators to each tested outcome feature
and returns tidy per-feature results with significance flags for both
NDE and NIE. When the dataset includes a mediator instrument (`Gm`), the
2-stage MR estimator
[`fit_iv2sls_mediation2`](https://seantbresnahan.com/iconic/reference/fit_iv2sls_mediation2.md)
(method "IV2SLS2") is also run. When the dataset includes path-specific
negative controls (`W1`, `W2`;), the two-stage proximal estimator
[`fit_pgc_mediation2`](https://seantbresnahan.com/iconic/reference/fit_pgc_mediation2.md)
is run as "PGC2" (without Gm) and "PGC2Gm" (with Gm, when Gm is also
present).

## Usage

``` r
analyze_mediation_robust(
  iteration_data,
  test_features = NULL,
  alpha = 0.05,
  n_cores = 1,
  se_method = c("delta", "bootstrap", "composite"),
  n_boot = 500
)
```

## Arguments

- iteration_data:

  Dataset list from
  [`run_single_iteration()`](https://seantbresnahan.com/iconic/reference/run_single_iteration.md)
  (or
  [`generate_toy_data()`](https://seantbresnahan.com/iconic/reference/generate_toy_data.md)).
  When `Gm` is present, the 2-stage MR estimator is included.

- test_features:

  Optional integer indices of outcome features to test. Default `NULL`
  (all features).

- alpha:

  Significance threshold for the significance flags. Default 0.05.

- n_cores:

  Number of parallel workers. Default 1 (sequential). Uses
  [`parallel::mclapply`](https://rdrr.io/r/parallel/mclapply.html) on
  Unix and a PSOCK cluster on Windows.

- se_method:

  "delta" (default), "bootstrap", or "composite". See
  [`iconic_estimate()`](https://seantbresnahan.com/iconic/reference/iconic_estimate.md)
  for details.

- n_boot:

  Number of bootstrap resamples when `se_method = "bootstrap"`. Default
  500.

## Value

Data frame: `feature`, `method`, `NDE`, `NDE_se`, `NDE_p`, `NIE`,
`NIE_se`, `NIE_p`, `NDE_significant`, `NIE_significant`.

## Details

Negative controls are always summarised over the full W panel for COCA,
so restricting `test_features` does not change its control summary. The
matrix-bridge PGC uses the full W panel.

A scalar-bridge variant
([`fit_pgc_scalar_mediation()`](https://seantbresnahan.com/iconic/reference/fit_pgc_scalar_mediation.md))
is exported for standalone use but is not included in the default
pipeline.
