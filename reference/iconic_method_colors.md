# Colour palette for iconic methods

Colour palette for iconic methods

## Usage

``` r
iconic_method_colors
```

## Value

A named character vector of colors for the eight ICONIC estimators.

## Examples

``` r
iconic_method_colors
#>     UNADJ    DIRECT      COCA    IV2SLS       PGC   IV2SLS2      PGC2    PGC2Gm 
#> "#888888" "#E07B00" "#3A9EC2" "#27A062" "#C455A8" "#0279EE" "#75A025" "#FD9BED" 
```
