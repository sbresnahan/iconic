# Default method display order

Default method display order

## Usage

``` r
iconic_method_order
```

## Value

A character vector giving the canonical display order of the eight
ICONIC estimators.

## Examples

``` r
iconic_method_order
#> [1] "UNADJ"   "DIRECT"  "COCA"    "IV2SLS"  "PGC"     "IV2SLS2" "PGC2"   
#> [8] "PGC2Gm" 
```
